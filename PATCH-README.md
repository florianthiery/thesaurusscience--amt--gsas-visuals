## Applying

This is a first commit into an empty repository, so "applying" is just
unzipping into a clone of it:

```bash
git clone https://github.com/florianthiery/thesaurusscience--amt--gsas-visuals.git
cd thesaurusscience--amt--gsas-visuals
unzip -o thesaurusscience--amt--gsas-visuals-patch.zip -d .
```

Nothing is overwritten - the repository was empty.

## What to run

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
python main.py --only scenario-01
```

This writes the four files listed above under
`scenario-01-symmetric-closure/img/`. Nothing else in the repo is generated at
this stage.

## How to verify

1. **Both figures exist and open** - `scenario-01-inverse-closure.png` should
   show two side-by-side "Before"/"After" panels with two concept pairs each;
   `scenario-01-data-flow.png` should show a five-box left-to-right pipeline.
2. **Rebuild is byte-identical** - run `python main.py --only scenario-01`
   again and compare: on Windows,
   `fc /b scenario-01-symmetric-closure\img\scenario-01-inverse-closure.svg <previous copy>`
   (or `cmp` on macOS/Linux) should report no difference.
3. **Nothing else changed** - `git status --short` lists exactly the eleven
   new source paths in the Contents table above, plus the four generated
   image files under `scenario-01-symmetric-closure/img/`, and nothing more.
